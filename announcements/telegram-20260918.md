## POST 1 — Mist-OS

🌫 **Mist-OS 5.0 Alpha — Android 17**
**Pixel 8 (shiba)** & **Pixel 8 Pro (husky)** · 18 Sep 2026 · UNOFFICIAL

shiba `20260918-2024` · 2.86 GB · MD5 `4fa05909bd9a1b67ed4c4864d11adb08`
husky `20260918-2050` · 2.87 GB · MD5 `0d5e02083e28d6b335a5712ed9cb46ab`

📥 https://sourceforge.net/projects/chiranz/files/mistos/

**Fixed in this build**
• **GPS was completely dead — fixed.** Confirmed with a real satellite fix: 3.1s TTFF, 5.5m accuracy, GPS/GLONASS/Galileo/BeiDou/QZSS/IRNSS + L5.
• **Wireless charging** node was unlabelled by the same bug — also fixed.
• **QS header and shade go pure black when blur is off**, instead of the Monet tint.
• **Settings → Wallpaper** opens the wallpaper app again (was opening Mistify's page).
• **New "Now Playing" entry** in Settings → Sound & vibration. Android System Intelligence disables its own settings screen after a Play update, so the entry used to just vanish.
• **Now Playing on AOD no longer shows the previous song** — it updates without waking the screen.
• SELinux is clean — one upstream-tracked denial left, system-wide.

**What this ROM ships**
• Real Google **Class-3 face unlock** (not the software one)
• Fingerprint, Quick Tap, Clear Calling, Now Playing on the lock screen
• Google Camera, JamesDSP, high brightness mode with a QS tile + custom sunlight threshold
• **MINI GApps baked in** — Play Store included, nothing extra to flash

**Known / by design**
• **No Updater app.** The official Mist OTA would replace this build wholesale, so it's removed. Update by sideloading the new zip.
• **Now Playing notifications need one manual toggle:** Settings → Notifications → Now Playing. The preinstalled blob doesn't declare that permission, so it can't be granted automatically.
• **AOD Now Playing updates about a minute after a track change.** That's how ASI listens for ambient music — not a bug.

Tested on both shiba and husky. VoLTE confirmed working.

## POST 2 — VoltageOS

⚡ **VoltageOS 6.1 — Android 17** · build 3
**Pixel 8 (shiba)** & **Pixel 8 Pro (husky)** · 18 Sep 2026 · UNOFFICIAL

shiba `20260918-2104` · 1.55 GB · MD5 `8935634d1107240ce53a412987edd779`
husky `20260918-2116` · 1.55 GB · MD5 `e0eb7b1f31bec3b5e66be2ded77c1e22`

📥 https://sourceforge.net/projects/chiranz/files/voltage/

**New in build 3**
• **Face unlock is now the real Google Class-3 one.** Builds 1 and 2 shipped a bundled software face unlock (Megvii/Sense) that registered itself as *the* face provider, so Android never touched the Pixel face hardware sitting in the blobs — weaker, and not usable for banking apps. Gone.

**Carried over from build 2**
• **GApps can be installed.** Build 1 sized every partition exact-fit, so any GApps package failed with "no space left on device". Now **1134 MB free on product**, 92 MB system, 91 MB system_ext.
• **Fingerprint works.** The Goodix hardware always ran, but Android was never told the device *has* a sensor, so Settings hid the whole section.
• Removed the **fake virtual fingerprint/face HALs** that sat alongside the real ones.
• Three **SELinux denials** fixed at boot.
• **`init_boot.img` is published** now, and `boot.img` is stamped with the right OS version (17) and patch level (2026-09).

**Corrections to earlier notes**
• The reported **recovery failure was tester error** — recovery works. Never a ROM issue.
• Battery rail-level stats are **not** missing. That earlier claim was wrong.

**⚠️ About Google apps — please read**
Voltage ships **GmsCompat** (GrapheneOS-style sandboxed Play) but **no app store** — and GmsCompat expects one.

We deliberately **do not bundle GrapheneOS's Apps store.** They've asked other systems not to redistribute their apps or rely on their servers, and that's their call to make.

To get Play:
1. Install the Apps store yourself → https://github.com/GrapheneOS/AppStore/releases
2. Install Play services + Play Store through it

Or flash a GApps package instead. **GmsCompat and flashed GApps are mutually exclusive — pick one.**

**Known issues**
• **eSIM needs GApps** and is untested with them. Report back if you try it.
• RCS messaging services don't start.

**Updating:** build 2 → build 3 dirty flashes fine, same keys.
Coming from build 1 (`0808` / `0848`) → **clean flash required**, the key set changed.

## POST 3 — Flashing guide

📦 **How to flash** — Pixel 8 / 8 Pro · same steps for both ROMs

**You need:** unlocked bootloader, latest platform-tools, a USB cable that carries data.
⚠️ A clean flash **wipes everything.** Back up first.

**Check your download before you flash anything**
```
md5sum <rom>.zip
```
Compare with the MD5 in the release post. A corrupt download is the #1 cause of "it won't boot".

━━━━━━━━━━━━━━━

**FIRST INSTALL** (from stock or another ROM)

1️⃣ Grab the ROM zip **and** the 5 images from your device's `img/` folder:
`boot.img` `init_boot.img` `dtbo.img` `vendor_boot.img` `vendor_kernel_boot.img`

2️⃣ Reboot to bootloader:
```
adb reboot bootloader
```

3️⃣ Flash the images:
```
fastboot flash boot boot.img
fastboot flash init_boot init_boot.img
fastboot flash dtbo dtbo.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash vendor_kernel_boot vendor_kernel_boot.img
```

4️⃣ Boot to recovery:
```
fastboot reboot recovery
```

5️⃣ In recovery: **Factory reset → Format data/factory reset.**
Not optional coming from another ROM — the encryption keys won't match and it won't boot.

6️⃣ **Apply update → Apply from ADB**, then on the PC:
```
adb sideload <rom>.zip
```

7️⃣ **➡️ Flashing GApps? Do it now** — see the section below, before you reboot.

8️⃣ Reboot to system. **First boot takes 5–10 minutes** and can sit on the logo a while. Leave it alone.

━━━━━━━━━━━━━━━

**GAPPS — vanilla builds only**

ℹ️ **Mist-OS users: skip this.** Mist already ships MINI GApps with the Play Store. Flashing a GApps package on top will break it.

This section is for **VoltageOS** and other vanilla builds.

⚠️ **It has to happen in this same recovery session, before the first boot.** Adding GApps to an already-booted ROM means formatting data and starting over.

Right after the ROM zip finishes sideloading, **without rebooting**:

1️⃣ Back in recovery, pick **Apply update → Apply from ADB** again
2️⃣ On the PC:
```
adb sideload <gapps>.zip
```
3️⃣ Now reboot to system.

**Which package?** NikGapps or MindTheGapps, matching **Android 17 / arm64**. Anything built for an older Android version will fail or boot-loop.

**VoltageOS specifics**
• Needs **build 2 or newer.** Build 1 sized the partitions exact-fit and every GApps package died with "no space left on device".
• **GApps replaces GmsCompat — you get one or the other.** Flash GApps *or* use sandboxed Play via the GrapheneOS Apps store. Never both.
• Pick a smaller package if you can. There's ~1.1 GB free on product, which is plenty for a core/basic set but not for the everything-included ones.

**If it fails with "no space"** — you're on build 1, or the package is too large. Get the latest build, or pick a leaner variant.

━━━━━━━━━━━━━━━

**UPDATING** (already on this ROM)

1️⃣ Reboot to recovery
2️⃣ **Apply update → Apply from ADB**
3️⃣ `adb sideload <rom>.zip`
4️⃣ Reboot. **No wipe needed.**

Mist has no OTA app on purpose, so sideloading is how you update.
Voltage: clean flash only if you're coming from build 1.
**On vanilla + GApps?** Re-sideload your GApps zip in the same session after the ROM zip, every time you update.

━━━━━━━━━━━━━━━

**Root (optional)**
Pixel 8 keeps its ramdisk in `init_boot`, so patch **`init_boot.img`** with Magisk, then:
```
fastboot flash init_boot magisk_patched.img
```
Do it **after** the ROM has booted once — not in the same session.

━━━━━━━━━━━━━━━

**Reporting a bug?** Include: device (shiba/husky), build date, clean or dirty flash, whether you flashed GApps, and a logcat if you can get one. "It doesn't work" can't be fixed.
